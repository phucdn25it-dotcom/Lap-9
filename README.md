# Lab 9 — Thực hành PHP

Bài 8 đến bài 15: CKEditor, upload ảnh, session/đăng nhập, phân trang, đánh giá sản phẩm, RSS, CAPTCHA và bình chọn.

## Chạy trên XAMPP

1. Clone repository vào `C:/xampp/htdocs/Lap-9`.
2. Bật Apache và MySQL.
3. Mở http://localhost/Lap-9/lab9/setup.php và bấm khởi tạo dữ liệu.
4. Mở http://localhost/Lap-9/lab9/ để chọn bài.

Tài khoản mẫu bài 10: `admin` / `admin123`.

Cấu hình MySQL trong `lab9/config.php`. Hướng dẫn chi tiết và thông tin thư viện trong [lab9/README.md](lab9/README.md).

PHP 8+, MySQL/MariaDB. CKEditor đã có trong mã nguồn, không cần cài npm/Composer.
